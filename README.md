# BeatSync 비트싱크

실시간 멀티플레이 한국어 음악 퀴즈 파티 웹 게임. **Spotify 무료(Free) 계정 지원** 및 **Apple Liquid Glass** 디자인 시스템 적용.

---

## 🌟 주요 특징

1. **Spotify 무료(Free) 계정 완벽 지원 (Premium 구독 불필요)**
   - Spotify Web Playback SDK의 프리미엄 강제 제한을 우회하여, **무료 계정 및 구독이 없는 플레이어도 30초 고음질 실음원 미리듣기로 퀴즈 플레이 가능**.
   - Spotify Web API 연동을 통해 공식 앨범 아트워크, 트랙 상세 정보, Spotify 바로가기 링크(`open.spotify.com/track/...`) 제공.
   - 공개 Spotify 플레이리스트 URL/ID 직접 입력 지원 및 K-Pop 히트곡, 레트로 가요, 글로벌 팝송 프리셋 제공.

2. **두 가지 게임 모드 & 1인 연습 모드**
   - **스피드 퀴즈 모드**: 30초 음원을 듣고 제목/가수를 선착순으로 가장 먼저 맞히는 모드 (Fuzzy 오타 및 한글/영어 별칭 허용).
   - **타임라인 모드 (Tactical Card Game)**: 시작 카드 2장으로 시작하여, 들리는 곡의 발매연도 슬롯(`+ 여기에 카드 배치`)을 추리하여 먼저 10장을 모으는 전략 카드 게임.
   - **1인 연습 모드 (`/practice`)**: 혼자서 다양한 트랙을 들으며 퀴즈를 풀어볼 수 있는 단독 연습실.

## 🚀 실행 방법

### 1. 윈도우 원클릭 실행 (가장 추천)
프로젝트 폴더에서 **`start.bat`** 파일을 더블 클릭하세요!
- Node.js 설치 및 필요한 패키지(`node_modules`)를 자동으로 점검하고 설치합니다.
- 백엔드 서버(포트 3001)와 프론트엔드 웹(포트 3000)을 동시에 기동합니다.
- 준비가 완료되면 **기본 브라우저에서 `http://127.0.0.1:3000` 화면이 자동으로 열립니다.**
- 게임을 완전히 종료하고 싶을 때는 콘솔 창에서 `Ctrl + C`를 누르거나 **`stop.bat`** 파일을 더블 클릭하면 모든 서버가 즉시 정리됩니다.

### 2. 터미널 명령어로 직접 실행
```sh
# 통합 실행 (백엔드 + 프론트엔드 + 브라우저 자동 오픈)
npm start

# 또는 각각 실행
# 터미널 1 (백엔드 서버, 포트 3001)
npm run dev:minimal

# 터미널 2 (프론트엔드 웹 앱, 포트 3000)
npm run dev:web
```
