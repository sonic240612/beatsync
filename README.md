# BeatSync (비트싱크)

**🔗 데모 사이트: https://beatsync-neon.vercel.app** *(※ 호스트 서버 가동 시 접속 가능)*

실시간 멀티플레이어 음악 퀴즈 & 타임라인 카드 배틀 웹 게임.  
**Spotify 무료(Free) 계정 완벽 지원**, **한·일·영 다국어 음차/번역 정답 엔진**, **Apple Liquid Glass UI** 디자인 시스템을 적용했습니다.

---

## 🌟 주요 기능

### 1. Spotify 대용량 플레이리스트 랜덤 분산 수집 & 100% 공용 HTTPS 스트리밍
- **전체 구간 랜덤 오프셋(Offset) 분산 수집**: 300곡, 1,000곡 이상의 대용량 플레이리스트에서도 앞쪽 곡만 반복되는 문제 없이, **전체 구간(초반·중반·후반)에서 무작위 오프셋으로 분산 샘플링**하여 매 게임마다 200~400곡 규모의 완전히 새로운 곡 풀(Pool)을 생성합니다.
- **100% 공용 HTTPS 오디오 스트리밍 (Mixed Content 차단 완벽 해결)**: 모든 곡에 Apple iTunes / Spotify 공식 HTTPS 스트리밍 CDN 링크(`https://audio-ssl.itunes.apple.com/...`)가 탑재되어, Vercel(HTTPS) 및 모바일 브라우저에서도 보안 차단 없이 깨끗하게 재생됩니다.
- **Premium 구독 불필요**: Spotify Web Playback SDK의 유료 구독 제한 없이, 무료 계정이나 비로그인 상태에서도 30초 고음질 미리듣기 음원으로 즉시 플레이할 수 있습니다.
- **곡별 실제 발매연도 & 개별 앨범 커버 추출**: 각 트랙의 **개별 앨범 커버**와 **원곡 실제 발매연도**를 정확히 가져옵니다.
- **중복 출제 방지**: 한 게임 세션 내에서 이전 라운드에 출제된 곡(동일 ID 또는 동일 곡명·아티스트)은 다시 나오지 않도록 자동 필터링됩니다.

### 2. 8가지 실시간 테마 & 커스텀 플레이리스트 (전 카테고리 실시간 셔플)
고정된 로컬 곡 파일에 머무르지 않고, **모든 테마가 스포티파이 공식 대표 차트에서 매 게임마다 실시간으로 수집**됩니다.
- **🇰🇷 K-Pop 메가 히트곡 (`kpop_hits`)**: 최신 멜론/스포티파이 대세곡 (*K-Pop ON!*, *Hot Hits Korea*, *K-Pop Generation* 등 실시간 셔플)
- **📼 90~2000년대 명곡 (`kpop_retro`)**: 추억의 가요 & 밀레니엄 히트 (*2000s K-Pop*, *90s K-Pop*, *싸이월드 감성 BGM* 등 실시간 셔플)
- **🇰🇷 K-Pop 전체 (`kpop_all`)**: 최신 아이돌곡부터 90년대 명곡까지 전 세대 시드 풀 통합 무작위 분산
- **🌐 글로벌 팝송 TOP (`pop_hits`)**: 빌보드 및 글로벌 1위곡 (*Today's Top Hits*, *Pop Rising*, *New Music Friday* 등 실시간 셔플)
- **🌍 Pop 전체 (`pop_all`)**: 80·90·00·10년대 및 록 명곡까지 전 시대 글로벌 팝 시드 풀 통합 무작위 분산
- **🇯🇵 J-Pop 히트곡 (`jpop_hits`)**: 최신 일본 대세곡 & 인기 애니송 (*J-Pop Now*, *Tokyo Super Hits*, *Anime Now* 등 실시간 셔플)
- **🇯🇵 J-Pop 전체 (`jpop_all`)**: J-Pop 명곡부터 최신 애니메이션 테마곡까지 통합 무작위 분산
- **🎲 Spotify 완전 랜덤 셔플 (`spotify_random`)**: K-Pop, Pop, J-Pop, Rock, Hip-hop 등 전 장르/전 시대 시드 풀에서 무작위 분산
- **🔗 Spotify 플레이리스트 (`spotify_playlist`)**: 원하는 Spotify 공개 플레이리스트 URL 또는 ID를 직접 입력해 대용량 풀로 플레이

### 3. 게임 모드 (1~8인 멀티플레이 & 1인 솔로 플레이 지원)
- **⚡ 스피드 퀴즈 모드 (`speed`)**
  - 음원을 듣고 곡 제목/가수를 가장 먼저 맞히는 실시간 순발력 퀴즈입니다.
  - **정답 판정 기준**(`제목만` / `가수만` / `제목 + 가수`), **라운드 수**(`10` / `20` / `30` / `50` / `100`곡), **미리듣기 재생 시간**(`5` / `15` / `30`초) 설정 및 라운드 스킵 기능을 지원합니다.
  - 정답 공개 시에는 곡 제목과 아티스트명을 **원문 기준**으로 깔끔하게 표시합니다.
- **⏳ 타임라인 카드 모드 (`timeline`)**
  - 각 플레이어가 시작 카드 2장(발매연도 공개)을 가지고 시작하며, 매 턴 재생되는 곡의 발매연도를 추리해 내 타임라인의 올바른 연대순 슬롯(`+ 여기에 배치`)에 카드를 끼워 넣는 전략 게임입니다.
  - **승리 목표 카드 수 슬라이더**: 호스트가 로비에서 승리 목표 카드 수를 **최소 8장 ~ 최대 20장(기본 10장)** 사이로 직접 조절할 수 있습니다.
  - **모바일 터치 & 휠 스크롤 편의성**: 터치스크린 사용자를 위한 `[ + 배치 ]` 버튼 터치 가이드와, 데스크톱에서 `Shift` 키 없이 **일반 마우스 휠 스크롤만으로 가로 스크롤**되는 타임라인 카드 컨테이너를 제공합니다.
- **👑 새로고침 시 호스트 권한 자동 복원 (세션 안정성)**
  - 게임 도중이나 대기실에서 브라우저를 새로고침(F5)해도 방장 권한을 다른 플레이어에게 빼앗기지 않고 즉시 호스트 상태를 복원합니다.
- **🔊 실시간 무중단 볼륨 조절**
  - 재생 중인 곡이 끊기거나 처음부터 다시 재생되지 않는 무중단 실시간 볼륨 조절 및 음소거 토글을 지원합니다.
  - 상단 팝업 창 및 대기실 인라인 컨트롤러를 통해 세밀한 슬라이더로 원하는 음량을 즉시 조절할 수 있습니다.
- **👁️ 방 코드 마스킹(가리기/보이기) 토글**
  - 방송이나 화면 공유 시 방 코드가 노출되지 않도록 기본 상태는 `••••••`로 가려져 있으며, 옆의 **눈 모양 아이콘 버튼**으로 언제든 보이기/숨기기를 전환하거나 복사할 수 있습니다.

### 4. 반응형 UI (데스크톱 와이드 2분할 & 모바일 최적화)
- **🖥️ 1280px (`xl`) 데스크톱 와이드 2분할 레이아웃**: `1280px` 이상의 데스크톱/와이드 모니터 환경에서는 좌측 고정 사이드바(플레이어 명단 / 실시간 스코어보드 / 타임라인 현황)와 우측 메인 아레나(로비 설정 패널 / 퀴즈 정답 입력창 / 플레이어)로 가로 2분할 배치되어 넓은 화면을 효율적으로 활용합니다.
- **📱 1280px 미만 단일 컬럼 수직 배치**: 태블릿, 모바일, 창을 줄인 환경 등 `1280px` 미만 해상도에서는 넉넉한 너비의 **단일 컬럼 수직 레이아웃**으로 자연스럽게 전환됩니다.
- **스마트폰(360px~430px) 완벽 대응**: 모바일 좁은 화면에서도 5~6개 옵션의 세그먼트 컨트롤이 짤리거나 가로 스크롤을 일으키지 않도록 자동 축소 및 텍스트 트리밍 처리가 되어 있습니다.
- **가상 키보드 가림 방지**: 스피드 퀴즈 모드에서 모바일 키보드가 올라올 때 정답 입력창이 화면 밖으로 밀려나지 않도록 사운드웨이브 높이가 모바일용으로 최적화되어 있습니다.
- **모바일 2단 헤더 레이아웃**: 좁은 화면에서도 타이머, 라운드 뱃지, 볼륨 버튼, 스킵 버튼이 깨지지 않고 2단으로 정돈되어 배치됩니다.

### 5. 한국어·일본어·영어 다국어 정답 판정 엔진
- **대규모 3개국어 공식 사전**: K-Pop, Pop, J-Pop, 애니메이션 OST, 보컬로이드, 버튜버 곡과 아티스트의 한국어·일본어·영어 공식 표기 및 통용 별칭(예: `ビビデバ` ↔ `비비디바`, `Time of Our Life` ↔ `한 페이지가 될 수 있게`)이 내장되어 있습니다.
- **일본어·외래어·로마자 곡명 발음 & 번역 매칭**:
  - 한자·가나 혼합 제목의 **한국어 발음(음차)** 및 **한국어 번역** 입력 모두 인정 (`さよならは言わない` → `사요나라와 이와나이` / `안녕은 말하지 않아`, `夜鷹 - Yodaka` → `요다카` / `쏙독새`, `烏 - Raven` → `카라스` / `까마귀` / `레이븐`).
  - 가타카나 외래어 제목의 자연스러운 한국어 외래어 표기 자동 변환 (`ポルターガイスト` → `폴터가이스트`, `スカート` → `스커트`, `シンギュラリティ` → `싱귤래리티`, `リコンティニュー` → `리컨티뉴`).
  - 로마자·영문 제목의 한국어 발음 매칭 (`YOROSHIKU!!!` → `요로시쿠`, `Vivarium` → `비바리움`, `Bloom` → `블룸`, `Liar` → `라이어`).
- **가수명 판정 규칙**:
  - **영어권 가수 & 단일 단어 가수**: `Taylor Swift`(`테일러 스위프트`), `Lilas`(`릴라스`), `Crush`(`크러쉬`) 등은 일부만 적으면 오답 처리되며 **풀네임**을 입력해야 정답으로 인정됩니다.
  - **일본어권 솔로 가수**: 한자/가나 표기(`米津玄師`, `幾田りら`)뿐 아니라 영문 로마자 표기(`Ayumu Imazu`, `Kento Nakajima`, `Yuki Chiba` 등)도 한국어로 **풀네임(`이마즈 아유무`, `나카지마 켄토`)** 또는 **이름만(`아유무`, `켄토`, `리라`, `켄시`)** 입력하면 정답 처리되고, **성만(`이마즈`, `나카지마`, `이쿠타`, `요네즈`)** 입력하면 오답 처리됩니다.
  - **한국 아티스트 영문 표기 양방향 호환**: Spotify에 영문으로 등록된 한국 가수(`Yerin Baek` ↔ `백예린`, `Lee Seung Yoon` ↔ `이승윤`, `AKMU` ↔ `악뮤`/`악동뮤지션`, `(G)I-DLE` ↔ `(여자)아이들`/`아이들`, `BOL4` ↔ `볼빨간사춘기`/`볼사`)도 한글·영문 모두 정답으로 인정됩니다.

### 6. Apple Liquid Glass UI & 비주얼 시스템
- **스넬의 법칙(Snell's Law) 광학 굴절 렌즈**: 세그먼트 컨트롤의 내부 글래스가 이동·드래그될 때 렌즈 테두리 곡면(6.0px)을 따라 텍스트가 사실적으로 굴절·왜곡되는 visionOS 스타일의 물리 시뮬레이션을 구현했습니다.
- **100% 완전 투명 글래스(Crystal-Clear Glass)**: 틴트나 인위적인 불투명 배경 없이 뒷배경과 텍스트를 깨끗하게 투과시키며, 상단 림 하이라이트와 부드러운 글래스 드롭 섀도우로 실감 나는 유리 질감을 완성했습니다.
- **입체 음각 트랙 홈(Recessed Track Groove)**: 다크/라이트 모드 모두 세그먼트 컨트롤과 슬라이더 트랙에 깊이 있는 인셋 섀도우를 적용하여 글래스 렌즈와 트랙 간의 확실한 입체 구분감을 제공합니다.
- **심플 테마(Simple Theme) & 고대비 라이트/다크 모드**: 배경 효과를 걷어낸 미니멀한 솔리드 블랙/화이트 심플 테마를 지원하며, 라이트 모드에서도 흰색 글씨 소실 없이 높은 시인성을 보장하는 다크 그린 액션 버튼과 산뜻한 파스텔 카드 스타일링을 적용했습니다.

```text
beatsync/
├── apps/
│   └── web/                  # Next.js 15 프론트엔드 (React 19, Tailwind CSS, Zustand, Socket.IO Client)
│       ├── app/              # 메인 로비(page.tsx), 스피드 모드(speed-mode.tsx), 타임라인 모드(timeline-mode.tsx)

├── server/                   # Express 5 + Socket.IO 실시간 게임 서버
│   ├── minimal.mjs           # 소켓 룸/세션 관리 및 오디오 프록시 서버 엔트리

│   ├── rules.js              # 정답 판정, 부제 분리, 아티스트 성/이름 규칙 엔진
│   ├── japanese-translit.js  # 한·일·영 공식 사전 및 가나/한자/외래어/로마자 음차 엔진
│   ├── spotify-provider.js   # Spotify Web API / Embed 스크래퍼 및 개별 곡 메타데이터(발매연도·커버·미리듣기) 추출기
│   └── preview-provider.js   # 음악 소스별 트랙 풀 생성 및 셔플/중복 제거 프로바이더
├── shared/
│   └── tracks.js             # 내장 K-Pop / 레트로 / Pop / J-Pop 큐레이션 트랙 카탈로그
├── scripts/                  # 서버·웹 통합 실행 스크립트 및 E2E 검증 스크립트
├── start.bat                 # [윈도우] 백엔드 + 프론트엔드 로컬 원클릭 실행 (127.0.0.1)
├── start-online.bat          # [윈도우] 외부 IP 접속 허용 통합 실행 (0.0.0.0, LAN/공유기 접속용)
├── stop.bat                  # 실행 중인 백엔드/프론트엔드 일괄 종료 배치파일
└── tests/                    # 정답 규칙, 게임 모드, Spotify 연동 단위/통합 테스트
```

## 🚀 실행 방법

### 1. 윈도우 원클릭 실행 (권장)
- **로컬 혼자 / 개발 플레이**: 프로젝트 폴더에서 **`start.bat`** 파일을 실행하세요.
  - Node.js 및 의존성 패키지(`node_modules`)를 확인하고 백엔드 서버(포트 `3001`)와 프론트엔드 웹(포트 `3000`)을 동시에 기동한 뒤 브라우저에서 `http://127.0.0.1:3000`을 엽니다.
- **같은 와이파이 / 외부 친구와 플레이**: **`start-online.bat`** 파일을 실행하세요.
  - 모든 네트워크 인터페이스(`0.0.0.0`)로 호스팅하여 공유기 내 스마트폰/친구 PC에서 내 PC IP 주소로 접속할 수 있습니다.
- 종료할 때는 콘솔에서 `Ctrl + C`를 누르거나 **`stop.bat`**을 실행하면 됩니다.

### 2. 터미널 명령어로 실행
```bash
# 의존성 설치
npm install
npm --prefix apps/web install

# 통합 실행 (백엔드 3001 + 프론트엔드 3000 + 브라우저 오픈)
npm start

# 개별 실행 시
npm run dev:minimal   # 백엔드 서버 (http://127.0.0.1:3001)
npm run dev:web       # 프론트엔드 웹 (http://127.0.0.1:3000)
```
