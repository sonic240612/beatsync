# BeatSync 구현 계약 및 계획

승인 목표: `mu5lkd5c-7axi9o`. 원본 `beatsync_prd.md`는 변경하지 않는다.

## 범위와 변경 사항
- 한국어 로컬 웹 게임. Next.js/React + Tailwind + Zustand, Express + Socket.io, TypeScript.
- Spotify Premium/Web Playback SDK 대신 최대 30초 미리듣기 공급자 추상화. 이번에는 직접 합성한 오디오와 가상 제목/가수/연도로 검증한다. 실제 곡은 아니며 화면에 데모 표시 및 연습용 카탈로그 제공.
- Spotify OAuth, 검색/플레이리스트/좋아요 및 실음원 공급자는 후속 작업. `PreviewProvider`가 연결 경계다. preview_url 가용성/이용 조건은 검증하지 않았고 실연동 완료라고 주장하지 않는다. 스크래핑하지 않는다.
- 타임라인은 정확한 연도 입력이 아니라 삽입 위치로 판정한다. 같은 연도 사이 경계는 포함한다. 시작 카드 2장, 10장 승리, 틀리거나 시간 초과면 폐기.
- 스피드 퀴즈 제목/가수/둘 다(별도 필드), 10/20/30 라운드, 5/15/30초. 첫 정답 1점, 무정답은 0점, 동점은 공동 우승. 정규화와 제한적 편집 거리, 명시적 별칭만 허용(번역 자동 추론 아님).
- 200ms 동기화는 보장하지 않는다. 서버 시각 왕복 추정 + 미래 시작 시각 + 늦은 재생 seek + 종료 시각으로 best-effort. 사용자의 오디오 동의가 필요하다. 재생 실패/버퍼링 표시, 무음 진행 가능.
- 영구 DB/계정/배포는 범위 밖. 서버 재시작 시 방 소멸. 로컬 사용을 기본으로 바인딩한다.

## 구조
- `app/`: 페이지, 반응형 스타일, 레이아웃
- `lib/`: Zustand 클라이언트 상태와 오디오 컨트롤
- `shared/`: 공개 타입. 현재 정답/덱/재접속 토큰은 공개 상태에 포함하지 않음
- `server/`: 입력 검증, 공급자, 서버 권위 상태 머신, Socket.io 어댑터
- `scripts/`: 합성 WAV 생성
- `tests/`: 규칙 단위 테스트 및 실제 Socket.io 통합 테스트
- `e2e/`: 격리 브라우저 세션으로 전체 흐름 검증

## 이벤트 계약
모든 변경 요청은 acknowledgement `{ok:true,...}` 또는 `{ok:false,error}`. 입력 길이와 enum/정수를 런타임에서 검증한다. socket의 서버측 멤버십만 신뢰한다. 각 게임 요청에 현재 roundId 포함하여 이전 라운드 지연 요청 거절.
- `room:create {name}` → `{playerId,token,state}`
- `room:join {name,code}` → 동일. 로비에서만 참가, 최대 8명.
- `room:resume {code,playerId,token}` → 동일. 비밀 토큰 기반 복구, 기존 연결 교체.
- `room:leave {}` → 멤버 삭제. 호스트 이양, 진행 중 턴/종료 처리.
- `room:configure {mode,target,rounds,snippetSeconds}` → 호스트/로비 전용
- `game:start {}` → 호스트, 2명 이상 연결됨. 덱 서버 셔플.
- `game:answer {roundId,title,artist}` → 해당 라운드/정답 유형만 검사
- `game:insert {roundId,index}` → 현재 턴 플레이어만, 자기 타임라인 유효 경계
- `game:reset {}` → 결과 화면 호스트 전용, 로비 복귀
- `clock:ping {}` → `{serverNow}`
- 서버 `room:state`: 전체 공개 상태(현재 오디오의 무작위 URL과 시작/종료 시각, 공개 카드/점수, 결과 단계에서만 정답). 토큰은 요청한 사용자에게만 전달.

## 상태와 수명
`lobby → playing → reveal → playing|finished`. 단일 Node 이벤트 루프에서 라운드 상태를 먼저 닫아 동시 정답 중복 점수를 방지. 서버 타이머가 라운드를 종료하며 클라이언트 시계는 판정 권한 없음. 테스트에서 주입식 시간/대기값 사용, 기본 운영 대기 4초.
연결 끊김은 60초 동안 복구 가능. 호스트 연결 끊김 시 연결된 사람에게 권한 이양. 타임라인 차례 중 끊김 시 라운드는 타임아웃하고 다음 연결된 사람에게 넘김. 모두 끊기면 타이머 중단 후 재접속 시 남은 상태 복원/만료 처리. 빈 방 삭제, 미접속 장기 방 정리, 방 수/참가자/이벤트 크기/빈도 제한.
미디어 주소는 라운드마다 무작위 토큰을 사용하며 현재/공개 직후 라운드만 노출. 브라우저에서 들리는 오디오 자체의 인식/분석 방지는 범위 밖.
